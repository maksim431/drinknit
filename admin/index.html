Админка сайта

Админка сохраняет правки прямо в репозиторий сайта на GitHub, сайт обновляется через минуту. Для входа нужен токен доступа GitHub.

Как получить токен
  1. Откройте GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → maksim431/drinknit.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Срок действия — на ваше усмотрение. Скопируйте токен и вставьте сюда.

Токен хранится только в этом браузере. Без него админка ничего не может изменить.
