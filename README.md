# Drinknit

Новогодние наборы с вязаными игрушками ручной работы. Чистые HTML, CSS и JS, без сборки — GitHub Pages раздаёт файлы как есть.

Десктоп и телефон получают разные версии. Скрипт в `<head>` смотрит на ширину и ориентацию окна (как раньше: телефон — ширина меньше 821 px или портретная ориентация) и подключает нужные стили и скрипт. При переходе через границу страница перезагружается.

**Десктоп** — новый макет, 8 экранов:
- разметка в `<template id="tpl-desktop">` внутри `index.html`
- `desktop.css` — экран 1920×1080 вписан в окно и стоит на месте; скролл (10 остановок, одна на жест колеса или клавишу) переключает сцены с анимациями. При загрузке — интро: коробка качается, собирает волшебную пыль, открывается со вспышкой и конфетти, затем появляется интерфейс (пропускается кнопкой «Пропустить» или Esc)
- `desktop.js` — интро, переходы между сценами, смена наборов, окно предмета, таймер, параллакс, музыкальная шкатулка. Наверху файла настройки: сколько наборов свободно, дата окончания приёма заказов, ссылки на мессенджеры, тексты наборов и предметов
- `assets/d/` — картинки нового макета

**Телефон** — прошлая версия без изменений:
- разметка в `index.html`
- `style.css` — вёрстка
- `app.js` — анимация: коробка покачивается, собирает волшебную пыль, открывается со вспышкой, конфетти и звёздами, затем появляются рамка и интерфейс; снег; музыкальная шкатулка по кнопке звука
- `assets/` — картинки из макета

Анимацию можно пропустить кнопкой «Пропустить» или клавишей Esc. При включённом в системе «уменьшении движения» экран показывается сразу в финальном виде.
