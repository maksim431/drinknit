# Drinknit

Новогодние наборы с вязаными игрушками ручной работы. Чистые HTML, CSS и JS, без сборки — GitHub Pages раздаёт файлы как есть.

Один лендинг с одними и теми же анимациями в двух раскладках. Скрипт в `<head>` смотрит на пропорции окна: горизонтальное окно (компьютер, планшет в альбомной ориентации) — кадр 1920×1080, вертикальное (телефон, вертикальный планшет) — кадр 430×932 по мобильному макету Figma с теми же блоками, `portrait.css` поверх `desktop.css`. Блоки «Сроки» и финальный выше экрана: на них прокрутка спускает экран по блоку. При повороте экрана страница перезагружается. На телефоне и планшете нет только параллакса от движения мыши.

**Горизонтальный кадр** — макет из Figma:
- разметка в `<template id="tpl-desktop">` внутри `index.html`
- `desktop.css` — экран 1920×1080 вписан в окно и стоит на месте, фоны сцен растянуты до краёв окна. При загрузке подарок покачивается в воздухе с подсказкой «Нажми на подарок»; по клику коробка деформируется, собирает волшебную пыль, открывается со вспышкой и конфетти, стикеры вылетают из коробки, затем появляется интерфейс (Esc — сразу к лендингу)
- `desktop.js` — интро; переходы между сценами привязаны к положению скролла (12 экранов прокрутки и подвал, у каждого перехода есть промежуточные состояния, лёгкое прилипание только в 16 % от экрана (у блока с наборами — 30 %, у карточек блока 3 — 20,8 %), доезжает до ближайшего экрана в любую сторону, стопор на каждом экране: прокрутка останавливается на ближайшем экране на 0,3 с); снег поверх всех сцен в два слоя; после начала скролла шапка меняется на компактный вариант из макета; смена наборов, окно предмета, таймер, параллакс. Последний экран — частые вопросы (тексты в `FAQ` в `data.js`), за ним при дальнейшей прокрутке выезжает подвал с разделами и контактами. Видео-переход между блоками 3 и 4 занимает 1,5 экрана прокрутки. Настройки (сколько наборов свободно, дата окончания приёма заказов, ссылки на мессенджеры, тексты наборов и предметов) — в `data.js`
- фоновая музыка на десктопе: `assets/audio/winter-time.mp3` (Vlad Gluschenko — Winter Time, CC BY 3.0), играет по кругу с приглушённым эффектом 40 % (срез верхних частот), громкость 10 % от исходной; включена по умолчанию, стартует сразу при загрузке, если браузер разрешает, иначе с первого клика или нажатия клавиши, выключается кнопкой в шапке. Настройки — `MUSIC` в `desktop.js`
- `assets/d/trans/` — 145 кадров видео-перехода из блока 3 в блок 4; кадры сменяются при скролле, грузятся, когда посетитель дошёл до блока 3
- `assets/d/` — картинки нового макета, `assets/d/sets/` — слои наборов S, M, L: весь набор и каждый предмет отдельно для подсветки по контуру и клика

**Телефон и вертикальный планшет** — те же разметка, `desktop.js` и анимации; координаты вертикального кадра для скрипта — в `L` в начале `desktop.js` (коробка, видео-переход, фон блока 4) и в `STICKERS_P` (места стикеров), раскладка блоков — в `portrait.css`.

Общие данные (настройки, наборы, тексты предметов, вопросы) — в `data.js`, их читают обе версии.

Анимацию можно пропустить кнопкой «Пропустить» или клавишей Esc. При включённом в системе «уменьшении движения» экран показывается сразу в финальном виде.

## Админка

`admin/` — админка сайта: https://drinknit.ru/admin/

- **Статистика** — данные Яндекс Метрики (визиты, воронка по блокам, действия, источники, устройства, все цели).
- **Тексты** — все тексты страницы по блокам, цифры и цены, подписи карточек, описания предметов, частые вопросы, заголовок для поиска.
- **Фото предметов** — фото в окне предмета: загрузка (сжимается в браузере), порядок, удаление.
- **Подключения** — номер счётчика Метрики, доступ к статистике, список целей, ссылки на мессенджеры.

Вход — fine-grained токен GitHub с правом Contents: Read and write на этот репозиторий. Правки сохраняются в `content.js`
(и фото в `assets/items/`), GitHub Pages публикует их примерно за минуту.

Файлы: `content.js` — редактируемое содержимое; `texts.js` — поиск текстов в вёрстке и подстановка правок
(общий для сайта и админки); `analytics.js` — счётчик Метрики и цели сайта.

## Поисковики и ИИ

Весь текст страницы рисуется скриптом из `<template>`, а роботы ИИ-сервисов JavaScript не выполняют. Поэтому в `index.html` лежат:

- статический текст страницы (`<main id="seo-static">`): скрипт сайта убирает его при запуске, посетитель его не видит; роботы и браузеры без JS видят обычную страницу;
- разметка schema.org (JSON-LD): организация, три набора с ценами, частые вопросы;
- метатег подтверждения Яндекс Вебмастера и `robots`.

Рядом: `robots.txt` (закрыты `/admin/` и `/tools/`), `sitemap.xml`, `llms.txt`.

Отдельные страницы под вопросы покупателей (обычный HTML, без анимации): `/kakoy-nabor-vybrat/`, `/podarok-uchitelyu/`, `/dostavka-i-oplata/`, `/o-masterskoy/`. Стили — `assets/pages.css`. Ссылки на них стоят в подвале главной и в `llms.txt`, адреса — в `sitemap.xml`.

Статический текст, JSON-LD, эти четыре страницы, `llms.txt`, `sitemap.xml` и мета-теги собирают `tools/build-seo.mjs` и `tools/seo-pages.mjs` из `content.js` (цены, составы, сроки, ссылки, вопросы). Руками файлы `*/index.html` этих страниц не правьте: изменения пропадут при следующем запуске.
**После правок текстов, цен или вопросов в админке запустите `node tools/build-seo.mjs` и закоммитьте результат** — иначе роботы увидят старые цены и тексты.
