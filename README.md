# Drinknit

Новогодние наборы с вязаными игрушками ручной работы. Чистые HTML, CSS и JS, без сборки — GitHub Pages раздаёт файлы как есть.

Десктоп и телефон получают разные версии. Скрипт в `<head>` смотрит на ширину и ориентацию окна (как раньше: телефон — ширина меньше 821 px или портретная ориентация) и подключает нужные стили и скрипт. При переходе через границу страница перезагружается.

**Десктоп** — новый макет, 8 экранов:
- разметка в `<template id="tpl-desktop">` внутри `index.html`
- `desktop.css` — экран 1920×1080 вписан в окно и стоит на месте, фоны сцен растянуты до краёв окна. При загрузке — интро: коробка качается, собирает волшебную пыль, открывается со вспышкой и конфетти, затем появляется интерфейс (пропускается кнопкой «Пропустить» или Esc)
- `desktop.js` — интро; переходы между сценами привязаны к положению скролла (11 экранов прокрутки, у каждого перехода есть промежуточные состояния, лёгкое прилипание только в 16 % от экрана, стопор на каждом экране: прокрутка останавливается на ближайшем экране на 0,3 с); снег поверх всех сцен в два слоя; после начала скролла шапка меняется на компактный вариант из макета; смена наборов, окно предмета, таймер, параллакс. Наверху файла настройки: сколько наборов свободно, дата окончания приёма заказов, ссылки на мессенджеры, тексты наборов и предметов
- музыки пока нет: кнопка звука только переключает два своих состояния из макета
- `assets/d/` — картинки нового макета, `assets/d/sets/` — слои наборов S, M, L: весь набор и каждый предмет отдельно для подсветки по контуру и клика

**Телефон** — прошлая версия без изменений:
- разметка в `index.html`
- `style.css` — вёрстка
- `app.js` — анимация: коробка покачивается, собирает волшебную пыль, открывается со вспышкой, конфетти и звёздами, затем появляются рамка и интерфейс; снег; музыкальная шкатулка по кнопке звука
- `assets/` — картинки из макета

Анимацию можно пропустить кнопкой «Пропустить» или клавишей Esc. При включённом в системе «уменьшении движения» экран показывается сразу в финальном виде.
