# Drinknit — главный экран

Новогодние наборы с вязаными игрушками ручной работы. Чистые HTML, CSS и JS, без сборки — GitHub Pages раздаёт файлы как есть.

- `index.html` — разметка экрана
- `style.css` — вёрстка по макету 1920×1080 (масштабируется под экран) и мобильная версия
- `app.js` — анимация: коробка покачивается, собирает волшебную пыль, открывается со вспышкой, конфетти и звёздами, затем появляются рамка и интерфейс; снег; музыкальная шкатулка по кнопке звука
- `assets/` — картинки из макета

Анимацию можно пропустить кнопкой «Пропустить» или клавишей Esc. При включённом в системе «уменьшении движения» экран показывается сразу в финальном виде.
